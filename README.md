# 剣道スコア表

剣道の団体戦のスコアを記録し、記録用紙の画像やテキストとして書き出すためのWebアプリです。

- 何人制にも対応（3・5・7人制はプリセット、任意のN人制も役職名を自動生成）
- 技（メ・コ・ド・ツ）と反則∆をタップで入力、勝者数・得本数・勝敗を自動計算
- 記録用紙そのままの画像（PNG）、テキスト、JSON、CSV、Markdown を出力
- データは端末内にのみ保存され、サーバーには送信されません
- オフライン動作（ホーム画面に追加するとアプリとして起動できます）

## 使い方

`index.html` をブラウザで開くだけで動きます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JavaScript すべて） |
| `sw.js` | オフライン動作用の Service Worker |
| `manifest.webmanifest` | ホーム画面に追加するための設定 |
| `icon.svg` / `icon-maskable.svg` | アイコン |
